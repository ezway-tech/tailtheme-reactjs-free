# Changelog

All notable changes to **TailTheme React Free** are documented here.

## [0.3.2] — 2026-05-26

### Changed

- README layout — centered hero, Pro / demo links on [tailtheme.ezway.tech](https://tailtheme.ezway.tech) and [tailtheme-demo.ezway.tech](https://tailtheme-demo.ezway.tech).
- Docs split — setup and development moved to [GUIDE.md](./GUIDE.md); release notes live in this file.

## [0.3.1] — 2026-05-21

### Added

- **Free edition** — MIT starter synced from TailTheme Pro via `build:lite`.
- **3 dashboards** — overview, SaaS, project.
- **Vertical samples** — SaaS and Project pages with static fixtures.
- **UI showcase** — `/app/ui` tokens and primitives.
- **App shell** — sidebar, header, breadcrumbs, command palette.
- **Auth & settings** — login, register, profile, account, appearance.
- **Marketing** — landing, pricing, about, contact.
- **Upgrade path** — sidebar CTA and `/app/upgrade` comparison vs Pro.

### Changed

- **Tooling** — ESLint, Prettier, Husky, Vitest, Playwright (no MSW in Free).
